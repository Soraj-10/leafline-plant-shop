# LeafLine — Premium Indoor Plant Shop

**Bringing Nature Home with Elegance & Intelligence**

A modern full-featured PHP & MySQL plant e-commerce website.

## Features
- Beautiful Plant Catalog
- Smart Care Tracker & Watering Reminders
- Shopping Cart with Discount Codes
- Wishlist System
- Loyalty Rewards
- Admin Dashboard
- Gift Ordering

## Setup
1. Import `database.sql` in phpMyAdmin
2. Visit `http://localhost/plantshop`
